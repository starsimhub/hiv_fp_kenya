# hiv_fp_kenya

FPsim + STIsim postpartum "one-stop shop" demo for Kenya. A single figure
showing that FPsim 3.6 (FPmod as `ss.Pregnancy`) runs in the same sim as
STIsim HIV, with one postnatal intervention acting on both — long-acting
contraception + long-acting PrEP delivered at the same visit.

Illustrative, not calibrated for HIV, not for decisions.

Full spec: [`docs/postpartum_one_stop_shop_spec.md`](docs/postpartum_one_stop_shop_spec.md).

Sibling repos: [`hiv_kenya`](https://github.com/starsimhub/hiv_kenya) (the
calibrated Kenya HIV model on stisim 1.7.0),
[`hiv_zambia`](https://github.com/starsimhub/hiv_zambia).
